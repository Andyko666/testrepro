# Unified LF80 code download

Download [HA_Gurobi_No787_LF80_Code.zip](HA_Gurobi_No787_LF80_Code.zip). Extract it into a new folder, copy your existing unchanged `data/` folder next to `run_model.py`, then double-click `run_windows.cmd`. Python 3.12 and a working Gurobi license are required.

Default: historical route LF > 0.80 applies phi=1.20; otherwise phi=1.00. `primary_assumptions.json` is the sole default-rule source. The program, examples, scenario labels and tests use this same rule.

This download contains code/configuration and generic instructions only. No Excel/PDF inputs, solver logs or operational results are included. New results are generated locally with explicit scenario labels.
