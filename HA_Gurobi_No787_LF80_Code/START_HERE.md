# Start Here

Extract this code archive into a new folder, copy your existing unchanged `data/` folder beside `run_model.py`, then double-click `run_windows.cmd`. Read `README.md` for setup, rules, comparisons, and limitations.

The default is historical LF > 0.80: demand x1.20; otherwise x1.00. Edit only `primary_assumptions.json` to change the default threshold. New results are written locally and identify the effective scenario.
